# Persistent internal workspace tabs

Approved in conversation on 2026-11-18. Signed-in users get application-wide tabs with independent navigation and UI snapshots, durable on this device. Only active UI mounts; background tasks survive screen unmount. Normal navigation uses current tab; + and explicit Open in app tab add tabs. Duplicate editable CV/job/letter/profile/portfolio/Coach identities focus existing tabs. New/last-closed tab goes Home. Ten completed recently-closed tabs retained; running closed tabs exempt until completion. Desktop/mobile accessible tab strip spans site and editor layouts. Global/auth/admin/help/billing/public routes stay outside. Initial deep links win; initial Studio Home restores last active.

Root provider under AccountProvider; versioned sessions/tabs/feature snapshots. Native Next routes preserve queries/hash; reserved _workspace identifies tabs. Typed snapshot hook and workspace-aware navigation; hydrate before feature initialization. IndexedDB snapshots/files, immediate in-memory updates, 250ms debounce, flush controlled navigation, saved only after commit. Existing repository/account records authoritative. Revision mismatches preserve conflicting drafts, never auto overwrite newer entity. Separate writable sessions per browser window. Corrupt snapshots isolated; storage errors preserve memory and disclose unavailable restart recovery.

Feature coverage: editor/guided/design/download/history/quality/export; makeover/import files/results; job board/forms/details/interview/notes/research; new/saved letters; gallery filters/themes/compare; portfolio drafts/preview; LinkedIn write/review; Coach prompt, skills, stories, cards. Shared drafts/handoffs become account/tab/feature scoped. No passwords, DOM/runtime/request handles in snapshots. Existing account preferences/entitlements/entities shared.

Task owner: uid/tabId/feature/operation generation/input revision. Shared tasks capture inputs, report progress/results only to originating snapshot, never steal navigation or overwrite later edits. Generated conflicts remain suggestions. Uploads/AI/creation/export survive tab changes/closure. Reload marks incomplete tasks interrupted; no automatic AI/publish/download replay. CV creation preallocates durable id. Finished background export provides download action.

Backend: optional Idempotency-Key UUID for job/letter create; account/operation/key receipt and entity atomically committed with quota. Same input replays current entity, changed input/deleted result conflicts without recreating. Receipts retained until account deletion. Add server revisions (legacy 0) to jobs/letters, persistent nullable Coach envelope revision. New clients send expectedRevision on manual/AI mutations; all writers increment resource revision (separate board revision). Generate outside transaction; conditional commit in memory/Firestore; stale output returns 409 with current record and generated suggestion, releases AI reservation. Optional X-Workspace-Owner assertion must match verified session, never grants access; mismatches rejected even visitor-capable endpoints.

Signout: freeze/preflight all same-owner windows, collect flush acknowledgements. Clean signout one click. Local-only drafts, failures, running work or unresponsive windows offer stay/retry, recovery archive, explicit discard. Export does not authorize clear. Archive includes existing importable CV backup, readable workflow JSON/text and attachments. Fence owner generations/writes before delete. Forced expiry/account replacement freezes old work; owner-gated recovery retained for original uid, no old writes under new cookie. No server cancellation guarantee for already authenticated requests.

Out of scope: guest tabs, cloud workspace sync, independent Coach threads, generic durable AI queue. Rollout switch WORKSPACE_TABS_ENABLED; backend compatibility first; no partial feature release. Tests: reducer/storage/routing/tasks, all feature restores, duplicate focus, background/close/reload races, idempotency and conditional commits in memory+Firestore, auth/multi-window/signout failures, mobile+a11y, full existing regressions. Required gates npm run verify, npm run test:store, npm run test:e2e.
